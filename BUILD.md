# Сборка и установка Навигатора

Приложение собирается в облаке на GitHub Actions (там есть Mac с Xcode), а на iPhone ставится с Windows через **Sideloadly** с обычным бесплатным Apple ID.

## 1. Собрать

1. Откройте репозиторий на GitHub → вкладка **Actions** → **iOS build** → **Run workflow**.
2. Выберите вариант:
   - **release** — готовое приложение, работает само по себе. Его же можно дать друзьям.
   - **development** — для разработки: код загружается с компьютера, правки видны сразу.
3. Через 20–40 минут внизу страницы запуска появится архив **Navigator-release** (или `-development`). Скачайте и распакуйте — внутри файл `.ipa`.

Готовую версию для друзей удобнее выпускать тегом — тогда `.ipa` появится на странице **Releases**:

```
git tag v1.0.0
git push origin v1.0.0
```

## 2. Установить на iPhone (Windows)

1. Установите [Sideloadly](https://sideloadly.io/), а также **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store).
2. Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
3. Перетащите `.ipa` в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone:
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить (телефон перезагрузится);
   - **Настройки → Основные → VPN и управление устройством** → выбрать свой Apple ID → **Доверять**.

### Ограничения бесплатного Apple ID

- Подпись действует **7 дней**. Потом приложение перестанет открываться — переустановите тот же `.ipa` через Sideloadly (данные сохранятся). В Sideloadly можно включить автообновление подписи по Wi‑Fi, пока компьютер включён.
- Не больше 3 своих приложений на одном Apple ID одновременно.
- Каждый друг ставит приложение **своим** Apple ID через Sideloadly на своём компьютере.

## 3. Разработка (вариант development)

1. Установите `Navigator-development.ipa` как описано выше.
2. На компьютере в папке проекта: `npx expo start`.
3. Телефон и компьютер — в одной Wi‑Fi сети. Откройте приложение на телефоне — оно найдёт сервер (или отсканируйте QR-код камерой).

Правки в коде появляются на телефоне сразу. Пересобирать нужно только при добавлении нативных библиотек или изменении `app.json`.

> Expo Go для этого проекта больше не подходит: карты MapLibre — нативный модуль, которого в Expo Go нет.

## Симуляция

На экране маршрута кнопка ▷ запускает виртуальную поездку. Во время неё внизу есть переключатель **Норма / Глушение / Подмена** — так можно проверить, как навигатор ведёт без GPS и игнорирует подменённые координаты, не выходя из дома.
